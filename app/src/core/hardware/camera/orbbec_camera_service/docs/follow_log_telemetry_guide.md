# Follow 实时位姿跟踪与遥测日志详解指南

本文档系统性地解析了 `FollowWorker` 及跟随核心算法输出的实时遥测日志（`[Follow]` 标签行），详细说明了每个字段的数学定义、物理意义、正常取值范围及常见异常排查方法。

---

## 1. 典型日志示例

```text
00:06:12 [INFO] camera.cpp:315: [Follow] # 17967  X=  +20.25 Y=   +1.16 Z=  -28.05 mm  rx=  +0.35 ry= -11.76 rz=  -0.80 deg  |t|=  34.62 |r|= 11.79  ok      /gicp   inl= 6098(0.81) sT= 0.13 sR=0.010  56.0ms  〔静默 74 帧 · 其间最大偏离 0.27mm/0.046deg〕  gyro=9/6 still=YES resid=0.07 dps
```

---

## 2. 字段分段与对照表

一条完整的遥测日志可分为 **6 大核心板块**：

### 2.1 帧序号与空间相对位姿

| 字段 | 示例值 | 单位 | 说明与物理含义 |
| :--- | :--- | :--- | :--- |
| **`# <num>`** | `# 17967` | 帧 | 从服务启动/重置起累计处理的跟随帧序号。 |
| **`X, Y, Z`** | `+20.25, +1.16, -28.05` | `mm` | 当前相机相对于**示教（Teach）基准位置**在相机坐标系下的三维平移偏移量。 |
| **`rx, ry, rz`** | `+0.35, -11.76, -0.80` | `deg` (°) | 当前相机相对于**示教基准姿态**的三轴欧拉角旋转偏移量（绕 X/Y/Z 轴旋转角度）。 |
| **`|t|`** | `34.62` | `mm` | 空间总平移偏离模长：$\|t\| = \sqrt{X^2 + Y^2 + Z^2}$。 |
| **`|r|`** | `11.79` | `deg` (°) | 空间总旋转偏离的测地线夹角（SO(3) 空间测地线距离模长）。 |

---

### 2.2 求解状态与解算器（Status / Estimator）

格式为 `状态 / 解算器`，例如 `ok / gicp`。

#### ① 状态字段（Status）
- **`ok`**：正常跟踪状态。当前解算出的位姿位于合法工作包络内，且通过了所有安全门限（离群门、不确定度门等）。
- **`lost`**：跟丢状态。稠密配准与稀疏特征均未收敛，或者有效内点数低于最低要求。
- **`out_of_envelope`**：超出示教包络。当前点云与示教参考地图重叠率低于 `min_inlier_ratio`（如 10%），说明相机已经移动到示教范围之外。
- **`rot_gated`**：离群门拦截。视觉计算出的帧间旋转与陀螺仪（IMU）硬件积分旋转偏差超过阈值（`gyro_rot_gate_deg`），判定为疑似假收敛坏帧。
- **`no_depth`**：有效深度点数不足（低于 `min_cloud_points`）。
- **`config_invalid`**：配置无效或参考地图为空。

#### ② 解算器字段（Estimator）
- **`gicp`**：由 **GICP（Generalized ICP）稠密点云配准算法**高精度解算成功。
- **`sparse`**：GICP 未收敛，但降级到 **CPU-SIFT / 稀疏特征 3D-3D 配准**成功求解。
- **`none`**：两个解算器均未成功，当前位姿保持上一可信位姿（Hold Last Good Pose）。

---

### 2.3 点云质量与置信度指标

| 字段 | 示例值 | 单位 | 说明与物理含义 |
| :--- | :--- | :--- | :--- |
| **`inl`** | `6098(0.81)` | 点数(比例) | `6098` 为与示教参考地图成功匹配的内点数（Inliers）；`(0.81)` 为内点比例（81% 重叠率）。比例越高，几何匹配越稳固。 |
| **`sT`** | `0.13` | `mm` | 平移估计的理论不确定度标准差 $\sigma_T = \max(\sigma_X, \sigma_Y, \sigma_Z)$。正常静态时通常在 $0.1 \sim 0.3\text{ mm}$。 |
| **`sR`** | `0.010` | `deg` (°) | 旋转估计的理论不确定度标准差 $\sigma_R = \max(\sigma_{rx}, \sigma_{ry}, \sigma_{rz})$。正常静态时通常在 $0.01^\circ \sim 0.03^\circ$。 |
| **`ms`** | `56.0ms` | `ms` | 本帧算法计算总耗时（含特征提取与点云配准）。在 15fps 取流下，该耗时必须稳定低于 **66.6ms**。 |

---

### 2.4 日志合并与平稳度（静默机制）

为了防止静止时控制台被海量无变化的重复日志淹没，系统引入了**静默日志压缩机制**：

- **`〔静默 N 帧 · 其间最大偏离 Xmm/Ydeg〕`**：
  - 说明在过去的 $N$ 帧期间，位姿变化极为微小（平移波动 $\le 1.0\text{ mm}$ 且旋转波动 $\le 0.1^\circ$），因此将这 $N$ 帧的遥测合并为一行输出。
  - 示例中 `〔静默 74 帧 · 其间最大偏离 0.27mm/0.046deg〕` 表示在过去约 5 秒（74 帧）内，相机最大物理抖动仅 0.27mm 和 0.046°，说明算法输出极其平稳。
- **`<保持上一位姿>`**：当前帧由于某种原因（如跟丢、出包络、离群门拦截）未采纳新解，系统安全锁存并沿用上一可信帧位姿。
- **`〔静止·旋转冻结 N 帧〕`**：陀螺仪确认相机物理静止，旋转通道已开启冻结保护，累计已平滑锁定 $N$ 帧。

### 2.5 陀螺仪（IMU）与静止检测状态

```text
gyro=9/6 cov=0.58 sd=1.00 sg=0.99 still=NO resid=0.07 dps gate=0.12/2.05
```

| 字段 | 示例值 | 说明与物理含义 |
| :--- | :--- | :--- |
| **`gyro=P/S`** | `gyro=9/6` | **`P`（`gyro_pushed`）**：本帧周期内从底层驱动接收并推入跟踪器的 IMU 样本数（此处为 9 条）。<br>**`S`（`gyro_samples`）**：在这一帧的积分时间窗口内，实际成功参与旋转积分计算的 IMU 样本数（此处为 6 条）。<br>注：$S > 0$ 表明时间戳动态对齐正常，积分窗口没有框空。 |
| **`cov`** | `0.58` | 滚动 $S/P$。**结构值 ≈ 0.58**（IMU 交付比帧交付慢约半个帧周期，窗口尾部那半帧的样本解算时还没到货，已由末样本常值补积补回）⇒ 低于 1 不是故障，明显低于 0.30 才是真在丢样本。 |
| **`sd` / `sg`** | `1.00` / `0.99` | 帧设备戳、陀螺戳各自相对**主机到达轴**的推进比率。健康值都 ≈1；哪一路明显偏离 1，那一路打的就是"语义戳"而非"时刻戳"。 |
| **`still`** | `YES` / `NO` | **陀螺仪静止判据结论**。<br>`YES`：检测器确认相机此刻处于完全静止状态，触发旋转通道冻结，消除 GICP 高频噪声；<br>`NO`：检测器检测到相机正在运动，旋转通道实时解冻跟随。<br>注意 `P=0` 时它恒为 `NO`，那是**没样本**而不是"在动"。 |
| **`resid`** | `0.07 dps` | **扣除硬件零偏后的角速度残差模长**（单位：`dps` = 度/秒，$\text{deg/s}$）。<br>计算公式：$\text{resid} = \|\omega_{\text{raw}} - \text{bias}\|$。<br>• 静止在桌上时：由于零偏已被扣除，残差处于纯传感器电路白噪声水平（通常在 $0.05 \sim 0.10\text{ dps}$）；<br>• 手持转动时：残差即为相机的真实物理旋转角速度（通常在 $20 \sim 60\text{ dps}$ 以上）。 |
| **`gate=e/l`** | `0.12/2.05` | **`e`**：本帧"视觉帧间旋转 vs 陀螺积分旋转"的测地线偏差；**`l`**：本帧**实际生效**的动态门限 $= 2.0° + 0.5 \times$ 本区间陀螺转角。两个数必须成对读：$e=3°$ 在静止帧是离群、在 $115°/\text{s}$ 帧是噪声。`l=0.00` 表示本帧没走到判据（无样本或无上一帧）。 |

**`P` 恒为 0 时（陀螺断供）怎么分成因**：看 `/api/v1/camera/follow/status` 的 `gyro` 组 ——
`alive=false` + `starved_frames` 单调上涨 = 已经报过 ERROR；再看 `callbacks`（驱动侧 IMU 回调累计数）：
**不涨** ⇒ 传感器/SDK 侧一帧都没交付（`start()` 成功 ≠ 在出数，需复位设备/重插）；
**在涨而 `pushed=0`** ⇒ 帧到了但全被 `toHostNs()==0` 丢弃（时间基未就绪或又被 `reset()`）。

## 3. 核心机制原理说明

### 3.1 什么是“零偏”（Zero Bias）与“残差”（Residual）？

1. **硬件零偏（Bias）**：
   - 陀螺仪在完全静止时，受芯片工艺与温漂影响，也会固定输出一个非零底数（例如实测约 $+0.99^\circ/\text{s}$）。
   - 如果不扣除该零偏，静置 1 分钟就会凭空累积出约 $60^\circ$ 的虚假旋转。
2. **两阶段零偏定标（Bootstrap & EMA）**：
   - **Phase 1（开机/示教定标）**：示教完成的瞬间相机静置在桌上，系统在前 100 个样本（0.5s @ 200Hz）内瞬间计算均值，精确锁定静态硬件零偏；
   - **Phase 2（在线自适应）**：仅在残差低于门限的静止期，通过极小学习率 EMA 缓慢跟踪温度漂移。
3. **残差（Residual）**：
   - 残差即剔除硬件零偏后的净角速度。静止时 $\text{resid} < 0.45\text{ dps}$（判定静止）；运动时 $\text{resid} \gg 0.60\text{ dps}$（瞬间解冻）。

### 3.2 离群门（Outlier Gate）机制

- **作用**：防止视觉在对称纹理或遮挡退化场景下发生“假收敛”或角度突变跳跃。
- **比对逻辑**：将视觉解算出的帧间旋转增量 $\Delta R_{\text{visual}}$ 与同时间段内陀螺仪高频物理积分得到的 $\Delta R_{\text{gyro}}$ 进行测地线距离比对。
- **判据**：若 $e > \text{gyro\_rot\_gate\_deg} + \text{gyro\_rot\_gate\_relax} \times \text{本区间陀螺转角}$（当前配置：下限 $2.0°$ + 斜率 $0.5°/°$），则判定为异常坏帧并予以拦截，避免机械臂受到错误脉冲冲击。
- **为什么门限必须跟着转角走**：$e$ 的主要来源是"帧周期 × 角速度估计误差"，转得越快 $e$ 越大且与转速成正比。固定门限因此在慢速时形同虚设（$10°$ 才拦，等于不拦）、在快速时误杀（手持快转的正常帧被当成坏帧连串锁死）。真机实测：斜率取 0.5 时 $e/l$ 的 p95 ≈ 0.40，既留了余量又拦得住真正的离群帧。

### 3.3 动态时间基对齐（`GyroTimeBase`）

- **背景**：相机图像帧数据量大，存在约 $350 \sim 450\text{ ms}$ 的 USB 排队与传输延迟；而 IMU 数据包小、传输几乎无延迟。
- **机制**：通过配对采集“设备曝光微秒戳 $\leftrightarrow$ 主机接收毫秒戳”，动态计算出最小传输时钟偏差，将陀螺仪样本统一投影到与图像帧完全一致的时间域中，确保旋转积分时间窗口严格对齐。

## 4. 常见异常日志诊断对照表

| 日志特征 | 发生原因 | 影响与系统表现 | 应对建议 |
| :--- | :--- | :--- | :--- |
| `陀螺时间基已定标: … 定标窗口内 IMU 回调=0 ⇒ …传感器一个字节都没交付` | `gyro_sensor_->start()` 没抛异常但设备端 IMU 流是死的（实测：一整轮回调计数恒为 0，且反复关开 follow、重启服务进程都救不回来）。与配置、时间基、跟踪器都无关。 | 静止冻结、离群门、帧间旋转初值**三条一起失效**：`still` 恒 `NO`、`gate` 恒 `0.00/0.00`，相机放桌上后旋转输出仍跟着视觉噪声抖（页面表现为仿真臂微晃）。跟踪本身照样 `ok`、帧率照旧 ⇒ 不喊就是静默降级。 | 复位设备（断电重插 / 重启板子）。开机日志里 `定标窗口内 IMU 回调` 回到 ≈50 才是恢复了。 |
| `陀螺断供：连续 30 帧零样本交付（缓冲 0 条）。成因 — …` | 同上，但从**帧侧**看到的事实（运行中途 IMU 停更也由这条抓，比定标那条覆盖更多工况）。后半句的成因由驱动回调计数增量自动指认：`传感器侧` = 回调也不涨；`时间基侧` = 回调在涨而样本全被 `toHostNs()==0` 丢弃。 | 同上三条失效。 | 传感器侧 ⇒ 复位设备；时间基侧 ⇒ 查 `gyro.time_ready` 与是否又有 `reset()`（换档/软重启）发生在采样之后。 |
| `rot_gated/none` 且连续拦截多帧 | 相机在做极高速剧烈甩动，或视觉与陀螺仪外参出现较大偏差。 | 位姿安全保持上一可信帧，机械臂不响应突变。 | 属于安全保护机制；看该帧的 `gate=err/limit`，若正常旋转也被拦说明斜率偏小（调 `gyro_rot_gate_relax`），而不是去放大固定门限。 |
| `out_of_envelope/none` (`inl` 比例过低) | 相机移动范围超出了示教时的视野覆盖范围。 | 触发保护，位姿保持在离开包络的边缘处。 | 重新执行示教（Teach），示教时将相机放置在预期运动范围的中心位置。 |
| `lost/none` 且 `compute > 90ms` | 场景特征严重退化、快速大范围移动超出搜索半径，导致 GICP 迭代超时未收敛。 | 位姿保持不变，出现跟随滞后感。 | 稍微放慢移动速度，或将 `voxel_m` 设为 0.020 加快收敛。 |
| `陀螺通道嫌疑失效：缓冲 N 条样本，却连续 30 帧的积分窗口一个样本都没框到` | 帧与陀螺不在同一时间域：缓冲里确实有样本（`push_gyro` 在收），而窗口既框不到任何一条、连末样本补积都没有可用的底 ⇒ 两域差了数量级（时间基没定标/没换算）。 | 帧间旋转初值与离群门静默停摆。 | 对照 `gyro.time_ready` / `offset` / `sd` / `sg`：比率不为 1 的那一路打的是语义戳；并确认 `gyro_horizon_ms >= 1000`。 |
| `静止冻结到达时限：强制解冻` | `gyro_max_freeze_ms` 被设置为较短时间（如 1500ms），防死锁保护定时触发。 | 静止时机械臂每隔一定周期微动一下。 | 生产环境中将 `gyro_max_freeze_ms` 设置为较大值（如 30000ms）或 0。 |
